# 变更管理规范

## 1. 变更分类

| 类型     | 定义                 | 审批流程      |
| -------- | -------------------- | ------------- |
| 紧急变更 | 修复 P0/P1 故障      | 口头审批即可  |
| 常规变更 | 功能发布、配置调整   | 提前 1 天申请 |
| 重大变更 | 架构调整、数据库变更 | 提前 1 周申请 |

## 2. 变更窗口

- 常规变更：周二、周四 14:00-17:00
- 禁止变更：周五、周末、节假日
- 紧急变更：不受窗口限制

## 3. 变更流程

1. 提交变更申请
2. 审批
3. 准备回滚方案
4. 执行变更
5. 验证
6. 记录归档

## 4. 变更后验证

- 健康检查通过
- 核心接口可用
- 监控指标正常（观察 30 分钟）
- 无新增告警

## 5. 变更失败处理

1. 立即执行回滚
2. 通知相关人员
3. 记录失败原因
