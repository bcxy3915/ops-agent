# 服务清单

## 1. order-service（订单服务）
- 职责：处理订单创建、查询、取消
- 端口：8081
- 负责人：张三
- 依赖：user-service、inventory-service、MySQL
- 关键接口：
  - POST /orders        创建订单
  - GET  /orders/{id}   查询订单
  - GET  /orders/slow   模拟慢查询（测试用）

## 2. user-service（用户服务）
- 职责：用户注册、登录、信息查询
- 端口：8082
- 负责人：李四
- 依赖：MySQL、Redis

## 3. inventory-service（库存服务）
- 职责：库存查询、扣减、回滚
- 端口：8083
- 负责人：王五
- 依赖：MySQL、Redis

## 4. gateway（网关）
- 职责：统一入口、路由转发、限流
- 端口：8080
- 负责人：张三

## 服务依赖关系
gateway → order-service → user-service / inventory-service
