# 部署手册

## 1. 部署环境

| 环境 | 地址             | 用途     |
| ---- | ---------------- | -------- |
| dev  | dev.example.com  | 开发环境 |
| test | test.example.com | 测试环境 |
| prod | prod.example.com | 生产环境 |

## 2. 部署流程

### 2.1 标准部署
1. 拉取最新代码
2. 执行 mvn clean package
3. 上传 jar 包到服务器
4. 停止旧服务：kill -15 <pid>
5. 启动新服务：nohup java -jar xxx.jar &
6. 验证健康检查：curl /actuator/health

### 2.2 灰度发布
1. 先部署 1 个实例
2. 观察 10 分钟指标
3. 无异常则继续部署剩余实例

## 3. 回滚流程

1. 找到上一个版本的 jar 包
2. 停止当前服务
3. 启动旧版本
4. 验证健康检查

## 4. 常见问题

### 4.1 部署后服务起不来
- 检查端口是否被占用
- 检查配置文件是否正确
- 检查依赖服务是否可用

### 4.2 部署后接口 404
- 检查 jar 包是否完整
- 检查路由配置

### 4.3 部署后性能下降
- 检查 JVM 参数是否变化
- 检查依赖版本是否变化
